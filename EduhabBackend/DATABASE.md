# База данных EduHub

## Обзор

PostgreSQL база данных для школьной системы EduHub. Управляется через Liquibase.

## Схема базы данных

### Таблицы (15 шт.)

| Таблица | Назначение | Ключевые связи |
|---------|-----------|----------------|
| `users` | Все пользователи системы | — |
| `teachers` | Профили учителей | `user_id` → `users(id)` |
| `students` | Профили учеников | `user_id` → `users(id)`, `group_id` → `student_groups(id)` |
| `student_groups` | Классы (7А, 9Б, 10А и т.д.) | — |
| `subjects` | Учебные предметы | — |
| `lessons` | Расписание уроков | `group_id` → `student_groups(id)`, `subject_id` → `subjects(id)`, `teacher_id` → `teachers(id)` |
| `grades` | Оценки учеников | `student_id` → `students(id)`, `subject_id` → `subjects(id)`, `teacher_id` → `teachers(id)` |
| `attendance` | Посещаемость | `student_id` → `students(id)`, `marked_by` → `teachers(id)` |
| `assignments` | Домашние задания | `subject_id` → `subjects(id)`, `teacher_id` → `teachers(id)`, `group_id` → `student_groups(id)` |
| `homework_completions` | Выполнение ДЗ учениками | `assignment_id` → `assignments(id)`, `student_id` → `students(id)` |
| `announcements` | Объявления | `author_id` → `teachers(id)`, `target_group_id` → `student_groups(id)` |
| `announcement_reads` | Отметки о прочтении | `announcement_id` → `announcements(id)`, `student_id` → `students(id)` |
| `notifications` | Уведомления | `user_id` → `users(id)` |
| `schedule_breaks` | Перемены в расписании | `group_id` → `student_groups(id)` |
| `user_settings` | Настройки пользователей | `user_id` → `users(id)` (PK) |

### ER-диаграмма (текстовая)

```
users ──┬── teachers
         ├── students ── student_groups
         ├── notifications
         └── user_settings

teachers ──── lessons
         └── grades
         └── assignments
         └── announcements

subjects ──── lessons
         ├── grades
         └── assignments

student_groups ── students
              ├── lessons
              ├── assignments
              ├── announcements
              └── schedule_breaks

students ──── grades
          ├── attendance
          ├── homework_completions
          └── announcement_reads
```
